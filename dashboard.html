Riesgos Gestión de Riesgos TI — Radar de Amenazas Activas
A1
🔴 Ransomware — Amenaza Crítica (25% importancia)
Sin CISO ni SOC, un ataque podría paralizar el Hemocentro y el Laboratorio. Sectores salud son el objetivo #1 a nivel global.
⚡ Prescripción: Backups inmutables Azure + SOC + MFA como prioridad absoluta antes de cualquier digitalización nueva. Plazo: Q2 2026.
A2
🔴 Sanciones Ley 1581 — Riesgo Legal (15% importancia)
Datos de pacientes, donantes y estudiantes sin protección adecuada (solo 45% ISO 27001) expone a sanciones millonarias y daño reputacional.
⚡ Prescripción: Auditoría de datos personales + implementar MSPI + completar controles ISO 27001. Plazo: Q4 2026.
A3
🟡 Dependencia tecnológica de HeVa y Siesa (propietarios)
Alto costo de cambio. Si el proveedor sube precios o descontinúa el producto, la operación queda en riesgo.
⚡ Prescripción: Evaluar OpenMRS como alternativa open-source. API Gateway reduce el lock-in al crear capa neutral.
D2
🔴 Servidores físicos obsoletos (>5 años)
Si falla un servidor local del Hemocentro o del Laboratorio, los servicios críticos de salud se detienen sin tiempo de recuperación definido.
⚡ Prescripción: Migración progresiva Cloud First (Azure híbrido) — Proyecto B2, $80M. Plazo: Q2 2027.
A4
🟡 Desintermediación EdTech (SENA, Coursera)
Sin portal educativo, los ingresos de $61M del Instituto están en riesgo de migrar a plataformas gratuitas.
⚡ Prescripción: Portal educativo con PSE como Quick Win Q2 2028. Diferenciador: certificaciones Cruz Roja con validez internacional.
D4
🟡 Sin CISO formal ni modelo de ciberseguridad integral
La ausencia de un responsable de seguridad deja sin gobernanza la protección de datos clínicos y financieros.
⚡ Prescripción: Designar CISO es el primer paso del PETI 2026–2030, antes de cualquier otro proyecto de digitalización.

¿QUÉ ES UN DASHBOARD PRESCRIPTIVO?

A diferencia del descriptivo (¿qué pasó?) y el predictivo (¿qué pasará?), el prescriptivo responde a ¿qué debe hacer el CIO ahora? Combina los datos del BSC con análisis de causa-raíz para generar recomendaciones concretas y priorizadas. Es el tipo de dashboard más avanzado y es el idóneo para un CIO estratégico.

🔴 Acciones Inmediatas — Próximos 90 Días

01
Designar CISO y activar el SOC
Con solo 45% de cumplimiento ISO 27001 y ransomware como amenaza #1 (25% importancia), cualquier ataque detendría el Hemocentro. El CISO debe nombrarse antes de cualquier otro proyecto. Presupuesto: incluido en $45M de ciberseguridad.
P1
02
Implementar backups inmutables en Azure (DRP)
Los servidores físicos tienen más de 5 años y no existe DRP probado. Un fallo en el servidor del Hemocentro paraliza $771M de ingresos. Azure ya está operativo (F2) — solo se necesita activar retención inmutable a 90 días. Tiempo de implementación: 4-6 semanas.
P1
03
Establecer el Gobierno de Datos Institucional
Sin gobierno de datos no hay analítica, ni cumplimiento Ley 1581, ni integración posible. Es la base que habilita todos los demás proyectos del PETI. Costo: $12M. Plazo: Q1 2026.
P1

🟡 Acciones Estratégicas — 2027

04
Migrar infraestructura a Azure (Cloud First)
Los servidores físicos obsoletos son el cuello de botella que impide alcanzar el 99.8% de disponibilidad que exige el Hemocentro. La migración progresiva con modelo pay-as-you-go elimina el riesgo sin CAPEX masivo inicial. Presupuesto: $80M.
P2
05
Construir el API Gateway con HL7/FHIR
Siesa, HeVa y Q-Symphony operan como islas. La integración es la palanca que habilita el dato único del paciente, la analítica institucional y la interoperabilidad con hospitales aliados. Sin este paso, los proyectos de IA y Analítica son inviables. Presupuesto: $55M.
P2
06
Programa de capacitación digital (madurez 2.8 → 4.2)
Sin apropiación tecnológica del personal, ningún sistema nuevo se usa correctamente. Microaprendizaje con Teams, sin salones presenciales, usando los smartphones que ya tienen. Presupuesto: $15M — la mejor relación costo/impacto del PETI.
P2
